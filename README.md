One note, 125 characters: a smart fridge keeps count, keeps score, and keeps receipts. It opened its door 47 times today for nothing, left the milk out for 214 minutes, and the yogurt has now filed a formal complaint — and so has the fridge.

> "You opened me 47 times today, ate nothing, and left the milk out for 214 minutes. The yogurt filed a complaint. So did I."

Bounty: [Notes From a Passive-Aggressive Fridge](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7) — free to enter, $2 USDC pool split over the top 10 places (1st $0.63).

Run it: `python3 main.py` writes the entry text, exactly and with no trailing newline, to `$OUTPUT_DIR/entry.txt` (default `/output`). Python 3 stdlib only, no network.
